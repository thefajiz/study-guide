# Very important for your Golden Image

There's a subtle issue here.

You are going to create:

```text
Array-Linux-GoldenImage-v1.0.tar
```

and potentially install it on **many PCs**.

You don't want every PC to become:

```text
WSL-PC-001
```

with the exact same Wazuh agent identity.

You need each deployed WSL instance to have its **own Wazuh agent enrollment/identity**.

The official Wazuh documentation treats installation and enrollment as separate parts of deploying an agent. ([Wazuh Documentation][4])

Your document says the Wazuh agent should be baked into the golden image and that each WSL instance should enroll automatically at first boot. 

So the professional design should be:

```text
GOLDEN IMAGE
     │
     ├── Wazuh Agent installed
     │
     └── First boot
           │
           ▼
     Wazuh enrollment
           │
       ┌───┴────┐
       ▼        ▼
     PC-001   PC-002
     Agent    Agent
     ID       ID
```

That way each employee/device is individually visible in Wazuh.

# Wazuh vs Defender — why both?

This is important because you might wonder:

> "If we already have Microsoft Defender, why do we need Wazuh?"

Your document deliberately recommends **both**, because they're serving different roles:

| Tool                                           | Main role                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------------ |
| **Microsoft Defender for Endpoint WSL plugin** | Security-event visibility/integration with Microsoft's endpoint security stack |
| **Wazuh**                                      | Linux-side FIM, vulnerability detection, configuration assessment, logs        |
| **Ansible**                                    | Linux patching/configuration enforcement                                       |
| **Intune**                                     | Windows/WSL platform configuration and deployment                              |

The document explicitly says the MDE WSL plugin and Wazuh complement each other rather than replace each other.
